# 消息中心接入指南与功能说明
消息中心提供消息发送、消息模版、发送任务等能力，业务方可通过 SDK 或无代码方式接入，目前支持飞书机器人、飞书群机器人、邮件三种通知方式。

## 写在前面：核心名词解释
- **应用**：一个应用可管理多个发送渠道（如飞书应用、飞书机器人）。  
- **秘钥**：用于 OpenAPI 接口调用，一个应用可拥有多个秘钥。  
- **发送渠道**：指发送的第三方对象，不同渠道通过渠道 ID（`ch_xxxx`）标识，可通过渠道 ID 发送到指定渠道。  


## 一、接入流程
### 1. 准备工作
#### 1.1 申请应用
联系 @孙梦影 申请应用，需提供以下信息：  
- 应用名称（如：“Devops 助手”）  
- 应用标识（如：“public_notify_center”）  

申请后，等待应用资源初始化完毕，可前往 **消息中心** 查看并配置应用。

#### 1.2 配置应用发送渠道
进入应用配置模块，目前支持配置的渠道为 **飞书应用** 和 **飞书自定义机器人**。

##### 飞书应用配置
1. **获取应用凭证**：  
   前往飞书开发者后台 → 进入应用 → 选择“凭证和基础信息” → 复制 AppID 和 App Secret 并填写。  
2. **申请必要能力**：  
   - 添加机器人功能；  
   - 申请接口权限：搜索并勾选 `im:message`、`im:message:send_as_bot`、`im:chat:readonly`（如需加急消息，额外申请 `im:message.urgent` 权限）；  
3. **发布应用**：在“版本管理与发布”中创建新版本并发布。

##### 飞书群机器人配置
1. 进入飞书群 → 点击右上角三个点 → “设置” → “群机器人”；  
2. 选择自定义机器人，复制 Webhook 地址和签名校验（可选）并填写。

#### 1.3 获取消息中心秘钥
消息中心的 access key 和秘钥用于接口调用，建议为同一应用的不同用户生成不同凭证，方便权限管理。

## 二、功能模块介绍
### 1. 消息模版
- **功能**：在消息中心后台定义和测试消息模版，模版变量用 `${}` 包裹。  
- **使用流程**：选择应用 → 点击“消息模版” → 编辑内容 → 通过测试发送验证格式。

### 2. 发送任务
- **特性**：支持无代码/少量代码实现定时、延时通知，具体包括：  
  - 发送渠道：飞书群消息、飞书个人消息（飞书应用支持两种；飞书机器人仅支持所在群）；  
  - 内容支持：使用已配置模版或直接编辑内容，支持变量动态替换；  
  - 发送频率：重复发送、定时发送、立即发送。

### 3. 发送记录
- **功能**：当消息未收到时，可通过该模块查看具体失败原因，便于排查问题。


## 三、消息内容构建
### 消息类型支持
- **飞书消息卡片**：通过飞书自带构建工具设计。  
- **Markdown/普通文本**：快速发送，支持自定义语法。

### 特殊语法支持
在飞书消息卡片、Markdown 中支持 @ 指定人，格式如下：  
- `<at id=open_id></at>`  
- `<at id=user_id></at>`  
- `<at email=test@email.com></at>`  
- `<at oa_uname=李韬></at>`  

### 消息加急
1. 先在应用后台申请 `im:message.urgent` 权限；  
2. 通过接口的 `urgent` 字段指定加急类型，发送加急消息。


## 四、常见问题 Q&A
### 如何获取群 ID？
- **方式一**：飞书设置 → 连续点击“关于” → 右键群聊复制群 ID。  
- **方式二**：  
  1. 将机器人加入群；  
  2. 调用接口查询机器人所在群，`chat_id` 即为群 ID：  
     https://open.feishu.cn/document/server-docs/group/chat/list?appId=cli_a524b3ab339d900d  

### 如何 @ 用户？
在飞书消息卡片或 Markdown 中使用以下格式：  
`<at id=open_id></at>`、`<at id=user_id></at>`、`<at email=xxx></at>` 或 `<at oa_uname=xxx></at>`。
